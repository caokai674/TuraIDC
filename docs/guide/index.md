# 使用者文档

该文档面向部署并运营 TuraIDC 的站长与运营人员

若需查看系统结构、接口或修改代码，请访问[开发者文档](../develop/index.md)。

## 简介

<p align="center">
    <img src="/branding/turaidc-logo.png" alt="TuraIDC Logo" width="400" />
</p>
TuraIDC 是一款面向 IDC / 云服务商的业务与财务经营系统。该系统覆盖商品管理、订单计费、自动开通、发票、充值、分销返佣、工单、通知等完整业务，提供管理后台、官网门户与用户控制台三端前端，并通过可扩展插件机制对接上游供应商与第三方服务。

## 核心能力

| 领域        | 能力                                                       |
| ----------- | ---------------------------------------------------------- |
| 🛒 商品     | 产品分组、配置项、库存管理、自动开通、多计费周期           |
| 💰 财务     | 支付、余额、充值、发票、退款、对账、流水明细               |
| 👤 用户管理 | 注册登录、实名认证（可选）、会员等级、分销与返佣、推广提现 |
| 🎫 工单系统 | 部门分配、工单回复、超时自动关闭、自动回复、上下游传递     |
| 🔔 通知     | 站内信、邮件、短信（模板可配置）                           |
| ⚙️ 自动化   | 调度任务、心跳监控、定时对账、日志归档                     |
| 🔌 多插件   | 供应商适配、支付网关、短信、验证码、邮件均以插件形式接入   |

## 横向对比

与部分友商的产品对比而言，我们的产品具有以下特性：

- **服务端计价**：金额、库存、优惠券、续费全部服务端重算并加锁，防止并发篡改。
- **完整审计日志**：关键资金、订单、后台操作留痕，支持导出与归档。
- **登录风控**：账号 + IP 级软锁定、验证码目标维度限流、多入口统一校验。
- **插件化架构**：供应商、支付、短信、验证码、实名、邮件均以插件接入，边界清晰、可替换。
- **自动化兜底**：调度任务、心跳监控、定时对账、失败重试与自动挂起/释放。
- **开源可审计**：AGPL-3.0-or-later 免费使用；可选商业授权（200 元/年）。

## 快速开始

1. 访问 [部署安装](deploy/index.md) 选择一种方式完成部署。
2. 访问 [部署与调度](deploy/scheduling.md) 配置服务端计划任务、队列与心跳。
3. 访问 [初始配置](configure/index.md) 修改站点名称与品牌、邮件与短信、支付渠道、上游供应商，然后再上架商品。
4. 创建测试账号对「下单 → 支付 → 自动开通 → 通知」的流程进行测试，确认可用后再进行公开。
5. 把 [备份与恢复](maintain/backup.md) 设定为定时任务，再对外销售。

## 环境自检

部署完成后可随时自检 PHP 版本、扩展与禁用函数；升级 PHP 或改动 `php.ini` 后也应进行复核：

```bash
cd backend
php artisan app:doctor          # 必选项：版本、扩展、禁用函数
php artisan app:doctor --all    # 附带列出建议安装但不阻断的扩展
```
